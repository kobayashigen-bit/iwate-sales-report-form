更新手順

  1. 上の「編集する」を押します。
  2. ブラウザの検索機能（Windowsは Ctrl + F）で変更したい文章を探します。
  3. 文章や選択肢を修正します。
  4. Commit changes... を押して保存します。
  5. 通常1〜3分後に公開ページへ反映されます。古い表示の場合は再読み込みしてください。

HTMLの < と > で囲まれた部分やJavaScriptを消すとフォームが動かなくなるため、文章だけを変更するときは文字部分だけを書き換えてください。GitHubの履歴からいつでも以前の状態へ戻せます。
